# 🧑‍💼 Employee Management System (EMS)

A full-stack **Employee Management System** built to manage employee records, attendance, and leave requests efficiently with role-based access control.

![EMS](https://meramonitor.com/employee-management-system/)

---

## 📌 Features

### 👤 User Roles
- **Admin**
  - Add, update, and delete employees
  - Approve or reject leave requests
  - View attendance and employee reports
- **Employee**
  - View personal profile
  - Apply for leave
  - Track attendance and leave status

---

### 📂 Employee Management
- Centralized employee database
- Manage employee details:
  - Name
  - Email
  - Department
  - Role
  - Joining Date
- Easy update and deletion of records

---

### 📝 Leave Management
- Employees can apply for leave
- Admin approval/rejection system
- Real-time leave status updates

---

### 🔐 Authentication & Authorization
- Secure login and registration
- Role-based access control (Admin / Employee)
- Protected routes using JWT

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JSON Web Tokens (JWT)
